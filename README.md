# Daybook — Personal finance

A single-file, local-first income and expense tracker covering **October 2026 through October 2036**.

## Use the app

Download `index.html` from this repository and open it in a modern browser. On first launch, enter your name and choose your currency. Your ledger will be saved in that browser on that device.

## Included

- Daily ledger for every day in the 121-month date range
- Income and expenses, with amount and comment/note fields
- Monthly income, expenses, balance, active-day count, and category totals
- The requested categories and subcategories, plus tools to add, rename, and remove your own
- JSON export and import for backups

## Privacy and backups

The app has no server or account sync. It stores the ledger in browser local storage. GitHub contains the app source only; entries you add in the browser are not sent to this repository. Clearing browser storage or using another browser/device will not carry your ledger over, so use **Export** to keep a backup and **Import** to restore it.
